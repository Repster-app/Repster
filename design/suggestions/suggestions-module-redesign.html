Where I'd land

Next up. It is the only one that changes what the section is for: not a list of what the engine computed, but the one instruction you need before you pick the bar up. It also handles the awkward states best — one set left stops looking like a list of one, and an unavailable set becomes a chip instead of a full strip.

Tiles is the pick if set count is the thing that bothers you — it is the only treatment whose height barely moves between three sets and six. Ticket is the one with a real opinion, and the one that carries a risk worth naming out loud: it moves the app's diagnostics voice onto the main surface.

One decision drives all four: does a set that is not next keep its own reason? Next up and Tiles say no — one reason, for the set you are about to do. Ledger says only when the set deviates. If the answer is that every set keeps its reason, none of these four is right and the current strips were closer than they look.
