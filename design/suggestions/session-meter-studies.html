Session meter studies

I was wrong about this last round. The model has a hard floor — maxFatigue = 0.25 — so a 75–100% scale is the model's own range, not a crop. The real problem is different and more interesting: fatigue plateaus rather than draining, so the needle lives in the top of that scale and barely moves unless rest is short. Six ways to draw that honestly.

Engine defaults: base rate 0.03, recovery constant 180 s, cap 0.25. A set at 8 reps and RIR 1 costs 3.9 points; rest gives back exp(−rest / 180) of what is standing.

Three things follow, and they decide every study below. One: the useful band is roughly 88–100%, so a bar anchored at the left of a 75–100 scale would sit near-full always and read as a lie — encode the deficit, which is zero-based, or use a position on a labelled scale. Two: fatigue converges — set 4 is barely worse than set 3 — so a meter that only shows a level hides the most interesting fact about it. Three: the thing that actually moves the number is rest, which makes this the one screen where the rest timer visibly pays for itself.

    Zero-based, so the length is the quantity — the one encoding here that survives a statistician. Empty at the start of every exercise, which is exactly right, and it grows in the direction the work goes.

  • Costs

    Inverts the intuition: a longer bar is worse. And "taken" is a modelled quantity presented as a measured one — the bar reads more certain than the number deserves.

Shows the plateau · hides the level

    The only study that shows rest doing something. Each downslope is recovery, and the dashed line answers the real question — is this going to keep getting worse? — with "no, it settles about here".

  • Costs

    It draws the rest you were supposed to take: the model falls back to your configured rest whenever a set has no recorded duration, so most downslopes are a setting, not a measurement. Also the busiest graphic here, in a section meant to be read between sets.

No meter at all. Put the fatigue on the step profile as a hollow dot — where this set would have sat if you were fresh — and the gap between the two dots is the whole story, in the unit you lift in.

Where I'd land

In steps, on the profile. It answers the fatigue question inside a chart the section already earns, in kilos rather than in a percentage nobody can calibrate, and it adds no new scale, no new label and no vertical space. A hollow dot above a filled one needs no explaining.

If you want a real meter, the deficit bar is the one that survives scrutiny — zero-based at the start of every exercise, growing in the direction of the work, with the model's own maximum as its end stop. The needle version is more truthful about the scale and almost motionless in use; the pips show the plateau but drop the level; the inline segments cost nothing and say almost nothing.

The plateau curve is the one I want to be right. It is the only drawing that shows rest paying you back, and it would make the rest timer visibly worth using — but until a set's real rest is recorded rather than assumed from your settings, those downslopes are drawing a preference as if it were a measurement. Fix the input and it becomes the best graphic in this whole exploration.
