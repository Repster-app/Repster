Templates, redrawn

Landing

B2b is the landing. The row tags are gone — they could not survive user-generated folder names, and no abbreviation the app invents would be right.

The chips carry folder identity instead, and the two states divide the work: a selected folder gives a clean flat list, and All falls back to grouped runs with full-width headers. Both artboards are stress-tested with a deliberately awkward folder name.

B2b · All (chosen)

B2b · ALL (chosen) — grouped runs, full-width headers, no tags.

A header has the whole row to work with, so a long folder name has somewhere to go and truncates at a readable size rather than inside a 9px pill. NOT IN A FOLDER is muted but present.

Tradeoff: this is close to the old B2 in All mode. The difference is that grouping is now the fallback, not the only mode — the chips are the primary way through.

B2b · Folder selected

B2b · FOLDER SELECTED — one folder, flat, no headers.

Headers would be redundant when every row belongs to the chip you just tapped, so they go, and the space becomes rows: six visible here against B2's three per folder.

The active chip is where the long name lives, and it can afford full width because the chip row scrolls sideways.

Tradeoff: a long name pushes the other chips off screen, so the folders you did not pick are one swipe away rather than visible.

Editor

Named More, not Special. In lifting apps "special set" is a term of art — Hevy uses it for drop sets and myo-reps — so the word promises set techniques and this menu delivers superset, note and folder. It would send you looking for the wrong thing.

The drawer is also thinner than it looks. DROP_SETS_SCOPING.md Decision 2 makes drop sets a SET annotation with real logged weights, and a template carries no weights, so there is nothing to prescribe. The other eleven set types are hidden by Decision 1. Rest time is per-exercise but dead — authored today, never read at runtime.

So More holds actions on the exercise, not special sets. When circuits, AMRAP and EMOM land — the decision record's Workout blocks — the grouping half may deserve its own word. Group with… is the candidate then, not now.

E1 · Accordion (chosen)

E1 · ACCORDION (chosen) — the action row now carries all three: a half-width Warmup, a full-width Working Set, and More holding everything else.

Warmup earns less width honestly — most exercises have none, and it is the rarer of the two adds. Working Set keeps the emphasis because it is what you press repeatedly.

More absorbs the header ellipsis entirely, so the unlabelled glyph is gone from every card. The menu now sits where you are already working instead of up in the header.

Tradeoff: acting on a COLLAPSED exercise means expanding it first. One extra tap for something you do once per exercise, in exchange for removing a mystery glyph from every row.

Superset · partner picker

SUPERSET · PARTNER PICKER the part that actually fixes it, and the part worth keeping.

Today you assign a LETTER, twice, on two exercises, with nothing saying a second step exists. Here you pick a PARTNER once, and the letter becomes an output: the sheet says these two become Superset B rather than asking you to choose B.

A superset of one — the state today's flow leaves you in — becomes unreachable.

Compatible with SUPERSETS_SCOPING.md §6: the letter is still the identity and colours still cycle every four. What changes is that the app assigns it.

How a folder gets made

HOW A FOLDER GETS MADE settled. User-created, because folders cannot be derived.

One nullable folder name on WorkoutTemplate. A folder exists because a template points at it and stops existing when the last one leaves. No entity, no lifecycle, no orphans.

Tradeoff: no ordering inside a folder and no folder metadata. Both want the dead Program model (Q6), which this does not foreclose.
