Remove from Template

Removing an exercise takes four steps today, and the last one is buried in a menu called More that sits below the set list. This moves it onto the card itself and renames it to say what it actually destroys.

The label

Delete Exercise
Matches the app, reads wrong

What every other screen says. Here it sounds like deleting the exercise from your library, which is not what happens.

Remove Exercise
Safe, says nothing

Softer than delete, but still silent about what it is being removed from.

Remove from Template
Chosen

Names the container, so the scope is unmistakable. Worth breaking the house Delete X pattern for.

Remove from Template

The existing button opens the same menu, so the visible path and the gesture lead to one place. Nothing here changes except the last item's wording.

What changes

Label

Remove exercise  →  Remove from Template Keeps the trash icon and the destructive role, so it still renders red and still sits last.

Entry point

The card gains a .contextMenu holding the existing exerciseActions Long press does nothing on these cards today, so the gesture is free. It is also what the exercise tab and the templates list already use.

Confirmation

A Remove from Template? alert before anything is removed Optional. It is the house pattern, but an undo toast would let the removal stay a single tap.

Untouched

The More button, the set rows, the drag grip, the card layout The menu gains a second way in; it does not move.

Still open

  • Confirmation or undo. An alert every time is friction on a deliberate action; a Removed Bench Press · Undo toast is cheaper and covers mis-taps better. The app has no toast pattern yet, so the alert is the conservative pick.
  • Case, elsewhere in the menu. The app Title-Cases menu items everywhere else, so Add note would become Add Note. Left alone here to keep the change targeted.
  • The last exercise. A template cannot save empty, so removing down to zero leaves the editor unsaveable. The live workout dodges this by hiding delete when only one exercise is left.
