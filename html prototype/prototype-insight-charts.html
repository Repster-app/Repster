Insight charts — what ships today

All seven chartKind values as they currently render, drawn from InsightChartViews.swift at the app's real sizes and design tokens, each inside the card that carries it. Detail text is clamped to two lines because that is what InsightCardView does while collapsed — the state these are read in.

The rule from §7.1: every insight chart names its subject and prints the figure the headline is about. The captions below mark each chart against it. The standing objection — “the card's text carries the numbers” — is what the two-line clamp defeats.

Potential directions

Eight shapes the current seven can't make. Each is aimed at a specific failure above rather than at variety — the note under every card says which rule it would serve, what it fixes, and what it costs.

None of these are built or agreed. Two need data the engine doesn't currently produce: nothing computes baseline spread, and no rule emits per-week or per-set distributions — chartValues carries aggregates only. Those are marked. The rest run on data that already exists.
